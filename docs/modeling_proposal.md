## 2. 파생변수(feature engineering) 제안

EDA에서 실제로 확인한 문제를 겨냥한 것들이다.

| 파생변수 | 목적 | 근거 |
|---|---|---|
| `sin/cos(2π·주차/52)` + 분기 더미 | 계절성 포착 | 검정 A/B에 이미 사용, `figures/10` 계절 편차(6.3배)로 재확인 |
| `conc_mean(t)`, `conc_mean(t-1)`, `conc_mean(t-2)`, rolling mean/std(N주) | 자기회귀 정보 | 표준 시계열 특징 |
| `conc_mean(t) / conc_3wk_avg(t)` | 모멘텀·희석 비율 | 검정 A의 종속변수 자체를 특징으로 재활용 |
| `conc_mean(t) ≥ 1.3×conc_base_avg(t)` (현재 경보 상태) | 강한 자기상관 신호 | 기준 모델이 이 규칙만으로 Macro-F1 0.49~0.66을 냄 — 그 자체가 강한 특징이라는 증거 |
| 지역별 z-score 또는 로그+연도 detrend | 스케일 정규화 | 시·도 간 최대 100배, 연도 간 중앙값 1000배 차이(README §5-2, `figures/05` — 중앙값 기준 27배 확인) |
| `conc_mean`으로 직접 계산한 증감률(클리핑/winsorize) | 이상치 제거 | `figures/07`에서 극단치는 0.1%뿐이지만 스케일 왜곡 위험 확인 |
| `n_sites`, `pop_sampled/pop_served`(1 초과분 별도 처리), 유효 처리장 수·처리인구(`first_sample_week≤t` 필터) | 측정 신뢰도 가중 | `figures/04`에서 처리장 수-농도 약한 상관(r=−0.38) 확인, `figures/09`에서 서울·대전만 중복집계 확인 |
| `missing_reason` 더미 | 결측 자체의 정보력 | `figures/06`에서 지역별로 다른 결측 패턴(서울 초반 장기 결측 등) 확인 |

## 3. 어떤 모델이 적합한가

문헌 리뷰 §4(알고리즘 비교, `docs/literature/review.md`)와 우리 EDA가 같은 방향을 가리킨다.

### 1차 후보 — 지역 pooled 트리 부스팅 (LightGBM/XGBoost)
17개 시·도를 하나의 모델로 묶어 학습(지역은 범주형 특징), §2의 파생변수를 입력으로 사용. 회귀(로그 타겟)와 분류를 각각 학습하거나, 회귀 예측값에 1.3배 규칙을 적용해 경보를 유도. 결측을 네이티브로 다루고 비선형 상호작용(지역×계절 등)을 잡기 좋다.

### 비교 기준선 — 시·도별 ARIMA/ETS 또는 GAM
문헌(Alhassan et al. 2025, `docs/literature/review.md` §1의 9번)이 1~2주 지평(이 과제의 t+2주와 근접)에서 ARIMA·GAM이 Prophet·단순회귀보다 꾸준히 우수하다고 보고한 것과 정확히 부합한다. 통계적으로 견고하고 해석 가능하다.

### 딥러닝(LSTM 등)은 후순위
README §5-6의 경고("대규모 딥러닝·GNN이 반드시 유리하지 않음")와, `reports/midterm/eda_findings.md` §2가 직접 재현해 확인한 사실(초기 fold n=763~984에서 검정 A의 부호까지 뒤집히는 불안정성)이 같은 방향을 가리킨다. 문헌에서 LSTM이 우세했던 사례(Ai et al. 2022)는 9개 지역사회·620건 규모로 우리 규모와 비슷하지만, walk-forward 초기 fold는 그보다 훨씬 작다는 점이 다르다. 데이터가 누적되는 후기 평가 창(2025-Q4 이후)에서 보조적으로 시도하는 것을 권장한다.

### 분류는 계절 인지가 핵심
어떤 모델을 쓰든 계절 변수를 넣지 않으면 3분기 쏠림(`figures/10`) 때문에 Macro-F1이 왜곡될 위험이 크다.

## 결론 — 권장 방향

| 우선순위 | 구성요소 |
|---|---|
| 1차 | 지역 pooled LightGBM/XGBoost (§2 파생변수 전체 입력) |
| 병행/앙상블 성분 | 시·도별 ARIMA·GAM (문헌상 단기 지평 강세) |
| 보조(후기 fold만) | LSTM 등 신경망 — 표본이 충분히 쌓인 뒤에만 |
| 필수 | 계절/분기 변수는 회귀·분류 모두에 반드시 포함 |
| 검토 필요(착수 전 확인) | DataON-02 CC-BY-NC 라이선스의 대회 이용 범위 — 운영기관 공지 확인 후 유역 강수 결합 시도 여부 결정 |

이 문서는 제안 단계이며, 실제 구현(모델 코드, `notebooks/` 실험, 성능 비교)은 사용자 확인 후 별도로 진행한다.
