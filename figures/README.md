# figures/ 그림 인덱스

`notebooks/01_fitting_period_eda.ipynb` 실행 결과로 생성된 그림들. 모든 그림은 fitting 기간(README §5-4·§6 검정 재현은 fold별 `train_until`, 기술통계·처리장 탐색은 데이터가 가장 많은 마지막 fold 2026-Q3=`train_until=2026-W25` 기준) 데이터만 사용했으며 평가 창 데이터는 쓰지 않았다.

## 01_national_trend.png — 전국 평균 하수 농도 추이

- **내용**: `national_weekly.csv`의 `conc_mean_national`(실선)과 `conc_3wk_avg`(점선)를 2023-W14~2026-W25(fitting 가능 구간 전체) 동안 로그축으로 그린 시계열. 회색 세로선 10개는 각 평가 창의 `train_until` 위치.
- **해석**: 2023년 수만~십만대에서 2026년 수백~수천대로 뚜렷한 하락 추세가 보인다(README §5-2의 연도별 중앙값 하락 55,555→8,520→5,350→1,359와 방향 일치). 2024-W52·2025-W52 부근의 급격한 하강-반등은 연말 미보고 결측 구간이다. `conc_mean_national`과 `conc_3wk_avg`가 대체로 겹쳐 움직이지만 급변 구간에서는 벌어진다 — README §4-3이 강조한 "3주 평균은 conc_mean의 단순 이동평균이 아니다"를 시각적으로 뒷받침.

## 02_testA_testB_by_fold.png — 검정 A·B 결과의 fold별 추이

- **내용**: (좌) 검정 A(강수 희석 부분상관, README §5-4) partial r의 fold별 값. (우) 검정 B(기상 추가 설명력 ΔR²)의 fold별 값. 둘 다 빨간 점선으로 README 전체데이터 보고값(A: −0.007, B: +0.0002)을 표시.
- **해석**: 두 검정 모두 표본이 작은 초기 fold(2024-Q2·Q3)에서 README와 다른 부호/큰 값을 보이다가, 표본이 커지는 후기 fold로 갈수록 README 값에 수렴한다 — "강수 희석 효과가 거의 없다"는 README 결론이 우연이 아니라 표본 크기가 늘며 안정화된 결과임을 보여준다.

## 03_xcorr_heatmap.png — 하수-임상 교차상관 히트맵 (fold × lag)

- **내용**: 행=fold의 `train_until`, 열=시차 k(−2~+4주), 값=`log10(conc_mean_national)`과 `log10(covid_cases_national)`의 피어슨 상관(README §6과 동일 정의).
- **해석**: 최대 상관이 나타나는 lag 위치가 fold(시간)에 따라 이동한다 — 2024년 fold는 lag 0/+1 우세(README와 일치)이지만 2025-W12 이후 fold들은 lag −1(임상이 하수보다 1주 선행)이 우세하거나 lag 0과 동률이다. README의 "lag 0/+1 최대"는 2026-W36까지 전체 데이터 기준이라, fitting 구간이 짧아지면 결과가 달라질 수 있음을 보여주는 핵심 그림.

## 04_plant_meta_explore.png — 처리장 수·처리인구 vs 평균 농도

- **내용**: 산점도. x=시·도 내 유효 처리장 수(`first_sample_week ≤ 2026-W25`), y=평균 `conc_mean`(로그축), 점 크기=처리인구 합.
- **해석**: 처리장이 적은 대구·세종·울산이 평균 농도가 높고 점 크기(처리인구)도 상대적으로 작다 — 처리장 수와 평균 농도 간 약한 음의 상관(r=−0.381, 탐색적 관찰이며 인과관계 아님). 표본이 17개 지역뿐이라 해석에 주의가 필요하다.

## 05_regional_conc_boxplot.png — 지역별 conc_mean 분포 (boxplot, 로그축)

- **내용**: 17개 시·도의 `conc_mean` 분포를 중앙값 오름차순으로 정렬한 boxplot(로그축), fitting 가능 전체 구간(~2026-W25) 데이터.
- **해석**: 중앙값 기준 최저(제주 약 980)와 최고(부산 약 26,700) 사이 약 **27배** 차이가 나고, 극단치(윗수염 바깥 점)는 대구·경남에서 최대 수백만~5천만대까지 치솟는다. README §5-2의 "시·도 간 100배 이상 차이"는 개별 관측값(연도 전체 최댓값 기준)의 차이이고, 이 그림의 27배는 fitting 구간의 **중앙값** 기준이라 수치가 다르다는 점에 유의 — 다만 방향(지역 간 스케일이 매우 다르다)은 동일하게 확인된다.

## 06_missingness_heatmap.png — conc_mean 결측 패턴 히트맵 (지역 × 주차)

- **내용**: 행=17개 시·도, 열=주차(2023-W14~2026-W25), 색=결측 사유(연한파랑=관측됨, 주황=`no_measurement`, 빨강=`no_source_row`).
- **해석**: 빨간 세로줄 3개(2023-W52·2024-W52·2025-W52 부근)는 전 지역이 동시에 결측되는 연말 미보고 구간으로, README §5-1의 51행과 정확히 대응한다. 그 외 주황색은 산발적으로 흩어져 있으며 서울 초기 구간(2023-W14~W40 부근)에 유독 긴 미측정 띠가 있는 것이 눈에 띈다 — 지역별 결측이 균일하지 않다는 것을 표보다 한눈에 보여준다.

## 07_wow_change_rate_outliers.png — wow_change_rate 이상치 분포

- **내용**: (좌) 전체 분포 히스토그램(symlog y축, n=2,613, 범위 −4,731~9,639). (우) −20~20 구간으로 확대한 히스토그램(전체의 99.4%가 이 구간에 몰려 있음).
- **해석**: README §5-3이 명시한 극단치는 실제로 전체의 0.1% 수준(|값|>100인 행 3개)에 불과하고, 나머지는 0 근처에 뾰족하게 몰려 있다. 이 열을 그대로 모델 입력으로 쓰면 소수의 극단치가 스케일을 왜곡할 수 있어 클리핑이나 강건한(robust) 변환이 필요함을 시각적으로 뒷받침한다.

## 08_precip_dilution_scatter.png — 강수-농도희석 원산점도

- **내용**: `log(1+precip_mm)`(x) vs `log10(conc_mean/conc_3wk_avg)`(y) 원본 산점도(지역·계절 통제 없음, n=2,667, 마지막 fold 기준). 빨간 선은 전체 데이터 단순 회귀선.
- **해석**: 회귀선 기울기가 0.0023으로 거의 수평이고, 점들이 강수량과 무관하게 넓게 흩어져 있다. 검정 A(부분상관, README §5-4)가 왜 −0.007이라는 거의 0에 가까운 값을 보고했는지를 잔차 계산 없이도 바로 확인할 수 있는 그림이다.

## 09_pop_sampled_vs_served.png — pop_sampled vs pop_served 중복집계

- **내용**: x=`pop_served`(시·도 고정값), y=`pop_sampled`(그 주 채취 처리장 처리인구 합). y=x 점선 기준, 빨간 점=`pop_sampled > pop_served`인 201행.
- **해석**: 대부분의 점은 대각선 아래(정상 범위)에 있지만, 빨간 점들이 대각선 위로 뚜렷이 벗어나 있다 — 서울(110행)·대전(91행)에서만 발생하며, README §5-5가 설명한 대로 과거 처리장(중랑B 등)이 현재 처리인구에 중복 합산된 결과다. `pop_sampled`를 신뢰도 가중치로 쓸 때 이 두 지역만 보정이 필요함을 시각적으로 확인.

## 10_alert_positive_rate.png — 급증 경보 양성 비율 (지역별·분기별)

- **내용**: (좌) 지역별 `target_alert_t2` 양성 비율 막대그래프(평균 대비 정렬). (우) 목표주 기준 분기별 양성 비율. 둘 다 `target_week_t2 ≤ 2026-W25`인 라벨만 사용(n=2,597).
- **해석**: 지역별 차이는 완만하다(전남 0.196~제주 0.358, 약 1.8배). 반면 **분기별 차이는 매우 크다**(2025-Q4 0.075~2025-Q3 0.475, 약 6.3배) — 2023-Q3·2024-Q3·2025-Q3(3분기)가 반복적으로 고점, 2024-Q2·2025-Q2·2025-Q4·2026-Q2가 저점을 보이는 뚜렷한 계절 패턴이다. 이는 이번 확장 EDA에서 새로 발견한 것으로, 분류 모델(Macro-F1) 설계 시 계절 변수(월/분기)를 반드시 반영해야 함을 시사한다.
